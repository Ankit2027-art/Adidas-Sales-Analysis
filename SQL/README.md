# Adidas Sales Analysis Using SQL (MySQL)

## About the Project

This project focuses on analyzing Adidas sales data using MySQL. The main objective is to explore sales performance, identify business trends, evaluate product and retailer performance, and generate meaningful business insights.

The analysis covers sales data from 2020 and 2021. It includes SQL queries ranging from basic database exploration to advanced SQL techniques.

This project is part of my Data Analytics learning journey, where I practiced using SQL to solve business-related questions and convert query results into meaningful insights.

## Project Objectives

- Analyze overall revenue, profit, and units sold.
- Understand product-wise sales and profitability.
- Evaluate retailer-wise sales performance.
- Explore regional, state-wise, and city-wise sales.
- Compare performance across different sales methods.
- Analyze monthly, quarterly, and yearly sales trends.
- Perform data quality checks and validate the dataset.
- Solve business questions using SQL.
- Generate business insights and data-driven recommendations.
